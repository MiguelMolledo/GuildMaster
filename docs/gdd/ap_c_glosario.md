## Apéndice C. Glosario

| Término | Significado |
|---|---|
| Sim | Capa `sim/`: estado y reglas, sin nodos. |
| Vista | Escena de `game/` que pinta parte del estado (mapa, interior, panel). |
| Orden | Petición de un actor al sim (`Buy`, `Hire`…), validada. |
| Puesto (WorkZone) | Lugar de un edificio donde una persona trabaja una receta. |
| Cola | Lista de recetas que los empleados de un edificio producen solos. |
| Escenario | Partida guardada que sirve de punto de partida para pruebas y bots. |
| Diana | Rango esperado de una medida de balance (`data/targets.json`). |
| Ritual | Comprobación obligatoria antes de dar algo por hecho. |
| Cuaderno | Página de novedades y decisiones del desarrollo. |
| Crónica | Diario de hechos de la partida (entrada del futuro narrador IA). |
| Subgrim | Hilo worker de Grimoire coordinado por el hilo manager. |
| Gate | Punto que necesita el visto bueno del owner. |
| [balance] | Cifra inicial que se ajusta con bots contra las dianas. |
| Encargo | Pedido de un NPC con objeto, cantidad, plazo, prima y penalización (4.5.6). |
| Recado de entrega | Compra en el mercado que llega sola al almacén de un edificio, con sobrecoste (4.5.7). |
| Libro de cuentas | Registro en el sim de todo movimiento de oro, con el registro de avisos (4.18). |
| Rutina | Horario por franjas de un personaje controlado (4.10.8). |
| Pausa activa | Pausa en la que se siguen dando órdenes, que se encolan por personaje (4.1). |
| Microevento | Suceso pequeño de datos que pide una decisión rápida (4.20). |
| Rivalidad | Valor 0-100 de una familia IA hacia otra; decide cuándo ataca (4.21). |
